# 逐屏差异清单（改版验收）

**对照对象**：`http://116.62.181.80:8793/`（GeoNexus Globe Console / 莫干数字地球）。
**规则**：以参照站为准；只记录**屏幕上看得见的差异**，每条差异给出「现状 / 参照站 / 结论」。
结论只有三种：**已一致**、**有意不同（说明理由）**、**未做（说明原因）**。

## 0. 怎么得到这些截图（可复现）

| 项 | 值 |
|---|---|
| 参照站截图 | `ref-01-landing.png`（首页）· `ref-02-cases.png`（案例）· `ref-03-data.png`（数据资源）· `ref-04-workbench.png`（工作台） |
| 我们的截图 | `ours-01-home.png` · `ours-02-map.png` · `ours-03-data.png` · `ours-04-cases.png` · `ours-05-workbench.png` · `ours-06-account.png` |
| 视口 | 1500×1000，headless Chrome（`--headless=new --enable-unsafe-swiftshader`），`--hide-scrollbars` |
| 登录 | `wt@local`（工作台演示账号）；工作台与个人中心按设计需要登录，其余模块游客可见 |
| 工具 | `scripts/shoot.mjs`（先取令牌写 localStorage，再导航截图）；引擎状态用 `/tmp/probe-case.mjs` 读 `document.documentElement.dataset` 与 `window.__gnxGlobe` |
| 服务 | 前端构建产物由 `:3302` 的 `server.js` 托管（改版验证实例） |

**参照站没有截到的模块**：「地图」模块的浮层组织来自参照站源码阅读（见 `README.md` §3），不是截图比对；这一屏的差异结论据此标注为「据源码」。

## 11. 仍然存在的差异（不打算在这次改版里解决）

| 差异 | 原因 | 影响的屏幕 |
|---|---|---|
| 卡片没有缩略图，只有「暂无预览」 | 平台没有栅格缩略图渲染服务；截图服务是本地脚本，不进服务端 | 数据资源 |
| 目录在 SDK 注册中心未起时回落到离线演示种子 | 演示可用性优先；`SourceTag` 已如实标注「离线演示数据」 | 数据资源 / 地图 / 个人中心 |
| 同一屏只能有一个地图卡（地图是单例） | Cesium viewer 与容器互斥，切页复用而不是多实例（多实例 1GB+ 内存） | 案例 / 工作台 |
| 工作台规划结果没有 aoi/bbox | `/api/plan` 当前返回里没有空间范围字段 | 工作台 |
| 没有编辑/保存工作流的接口 | 规划器只读 | 工作台 |
| `GET /api/jobs/:id` 未实现 | 作业详情接口缺失 | 工作台 |
| 窄屏（<1100px）只做了基础折行 | 本次验收视口是 1500×1000 | 地图 / 案例 |
| 参照站「地图」模块无截图 | 当时只采了首页/案例/数据/工作台四屏 | 地图 |
